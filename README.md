# Sprint_5

UI-автотесты на Selenium и Python для учебного сервиса Доска.

Стек проекта:
- Python
- pytest
- Selenium WebDriver
- Google Chrome

Структура проекта:
- tests/ - тесты и фикстуры
- page_objects/ - методы работы со страницами
- locators.py - все локаторы проекта
- data.py - тестовые данные и фабрики данных

Покрытые сценарии:
- регистрация нового пользователя;
- регистрация с невалидным email;
- регистрация существующего пользователя;
- login пользователя;
- logout пользователя;
- попытка создать объявление неавторизованным пользователем;
- создание объявления авторизованным пользователем.

Как запустить тесты:
1. Установить Google Chrome.
2. Установить зависимости командой `pip install -r requirements.txt`.
3. Выполнить команду `pytest -v` в корне проекта.
